Windows x64 development preview with setup EXE, MSI and portable ZIP.

- Ctrl+click HTTP/HTTPS and www. links in terminal output.
- Independent application windows with Ctrl+Shift+N.
- Native Windows snapping and maximize-button hit testing.
- Inline Kitty graphics for Codex CLI pets, with a pinned private ConPTY runtime.

The setup EXE wraps the exact same per-user MSI. Both install one application
with one uninstaller. The portable ZIP needs no installation; extract it and
run `Start-Portable.cmd` for a separate profile.

Packages are unsigned. Real install/upgrade/uninstall testing remains outstanding.
This preview does not replace the stable/latest release.
